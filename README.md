# Pixis

Ein Spiel über prozedurale Kreaturen, gebaut aus **Signed Distance Fields (SDF)** in einer eigenen Engine.
Kreaturen werden aus einem Genom erzeugt, als weiche SDF-Körper gerendert, prozedural animiert und
bekommen über ihre Körperteile echte Fähigkeiten (laufen, schwimmen, fliegen, beißen, leuchten …).
